# Ranking de Hamburgueserías

## Objetivo del proyecto

Este proyecto consiste en una aplicación Java con interfaz gráfica mediante Swing que permite gestionar un ranking de hamburgueserías.

La aplicación permite añadir, editar, mostrar y eliminar registros. Los datos se almacenan en memoria durante la ejecución del programa, por lo que no se guardan al cerrar la aplicación.

## Funcionalidades

- Añadir una hamburguesería.
- Editar una hamburguesería existente.
- Mostrar el ranking ordenado por puntuación de forma descendente.
- Eliminar una hamburguesería.
- Salir del programa desde el menú principal.

## Datos de cada hamburguesería

Cada hamburguesería contiene los siguientes datos:

- Nombre.
- Ubicación.
- Especialidad.
- Puntuación del 1 al 5.

## Manual de usuario

Al ejecutar el programa aparecerá un menú principal con cinco opciones:

1. Añadir hamburguesería.
2. Editar hamburguesería.
3. Mostrar hamburgueserías.
4. Eliminar hamburguesería.
5. Salir.

El usuario debe introducir el número correspondiente a la opción que desea realizar.

La única forma correcta de cerrar el programa es seleccionando la opción 5 del menú principal.
